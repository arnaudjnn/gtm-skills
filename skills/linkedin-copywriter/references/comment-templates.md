# LinkedIn comment templates

Seven templates, every comment maps to one. Picking the template up front prevents drift. Sweet spot 200–350 chars; hard cap 1,250.

## 1. Missing-Piece

Add the angle the OP didn't cover. Don't disagree; extend.

**Use when:** OP's post is correct but incomplete.

**Template:**
```
The piece I'd add: <specific complementary insight, ideally with one number or named entity>.
```

**Example:**
```
The piece I'd add: the same dynamic shows up in onboarding. Companies that
add 1-minute-to-value onboarding see 38% better D14 retention than the ones
that ship a polished 8-step tour.
```

## 2. Answer-the-Closing-Question

OP closed with a question? Directly answer it. Most commenters generalize; you specify.

**Use when:** the post ends with "What do you think?" / "Have you seen this?" / "How are you handling X?"

**Template:**
```
<direct answer in one sentence>. <one specific data point or example>.
<one-line takeaway>.
```

**Example:**
```
We solved this with a 48-hour reply SLA, no exceptions. The day we let one
ticket slip past 48h, our churn from that cohort went from 6% to 14%. The
SLA isn't the strategy — it's the only metric that ever moved.
```

## 3. Data-First

Lead with your number. Reddit users want sources; LinkedIn users want proof.

**Use when:** OP made a general claim and you have specific data.

**Template:**
```
We ran this in <specific scope>. <Result with a specific number>.
<One-sentence interpretation>.
```

**Example:**
```
We ran this across 600 sales calls last quarter. Reps who used the "what
changed in your team this month?" question booked 31% more second meetings.
The follow-on was the variable, not the discovery question itself.
```

## 4. Practitioner Observation

Speak from direct experience. No generalizations.

**Use when:** OP is theorizing and you've actually shipped this.

**Template:**
```
What this matches in my work: <specific anecdote with named tool / company / metric>.
<One sentence on the gotcha that's missing from the post>.
```

**Example:**
```
What this matches in my work: we tried both Notion and Linear for the same
team in 2024. Linear won not because of the issue tracker but because the
keyboard shortcuts removed three clicks per ticket. The shortcut budget is
the thing that compounds.
```

## 5. Counter-with-Concession

Disagree productively. Concede the part that's true, then push back on the specific part that isn't.

**Use when:** OP's framing is half-right.

**Template:**
```
Agreed on <specific part that's correct>. The place I'd push back is on
<specific part that's wrong>: <one-sentence reason with evidence>.
```

**Example:**
```
Agreed AI agents reshape tier-1 support. The place I'd push back is on
calling knowledge bases a liability — bases aren't dead, they're just no
longer the user-facing surface. The agent reads from one. That's a promotion,
not a death sentence.
```

## 6. Quotable Reframe

Restate the OP's idea in a sharper one-liner. Earns the most reactions because the OP often re-shares.

**Use when:** OP's core insight is buried in a long post.

**Template:**
```
The way I'd compress this: <punchy one-line reframe>.
<Optional second line: the implication>.
```

**Example:**
```
The way I'd compress this: the playbook that gets you to product-market fit
is the same one that prevents you from scaling past it.
The hires you make next quarter should be the people who'd have refused to
work for you 18 months ago.
```

## 7. Ask-a-Sharper-Question

Pose the next-level question the OP's post doesn't answer. Bonus if OP replies; you've earned a thread.

**Use when:** OP's post opens a door but doesn't walk through it.

**Template:**
```
The question this opens for me: <specific harder question that follows
from the post's framing>.
<Optional: one-sentence why-this-question-matters>.
```

**Example:**
```
The question this opens for me: if "speed to value" is the metric, who on
the team owns it? PM, Ops, and CS all touch it; usually none of them are
measured on it. That gap is where the metric goes to die.
```

## Banned comment patterns

- "Great point!" / "Love this!" — sycophancy ban (see anti-ai.md)
- "This!" or "💯" as the only content
- Restatement of OP's post without adding new info
- "Couldn't agree more" — adds nothing
- Two-em-dashed sandwiches ("Yes — and also — no")
- Generic upbeat closer: "Thoughts?", "Curious to hear others", "What do you think?"
