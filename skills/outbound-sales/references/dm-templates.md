# LinkedIn DM templates

Five templates, each keyed to a signal type. LinkedIn DMs are NOT short emails. The register is different — more conversational, more scannable, less salesy. The recipient is on their phone, scrolling fast, and the preview pane truncates at the top of the thread.

## Universal rules

- **≤ 60 words total.** LinkedIn truncates in the conversation list at ~75 chars and in the panel preview at ~150. Anything past 60 words pushes the CTA below the fold.
- **No subject line.** LinkedIn DMs don't have one; if your tool inserts one, drop it.
- **No "Hope this finds you well" / "Hope you're having a great week".** Instant delete.
- **First DM doesn't pitch a meeting.** The first DM exists to start a thread, not close one.
- **No emoji** unless the recipient's recent posts use them. Match their frequency, don't maximize.
- **No URLs in the first DM.** LinkedIn's spam filter weights DMs with external links heavily. Save links for DM #2 after a reply.
- **No corporate sign-off.** Just first name. Or no sign-off at all.

## Template 1 — Hiring-Sales-Rep-Repost

```
Hey {First},

Saw the SDR role got re-listed at {Company}. Usually means the last
one didn't stick.

We've seen this hit hardest when the playbook hasn't been updated since
the team was half the size. {Named peer} fixed it with {one specific
change}.

Worth a quick compare?
```

Word count: ~50. Anti-pattern: don't say "I noticed". The signal is the re-listing; "noticed" is filler.

## Template 2 — Trustpilot Negative Support

```
Hey {First},

Saw {N} negative Trustpilot reviews about support response time over
the last month. The common thread looked like {specific theme}.

Usually means ticket volume jumped past where the team was sized for.
{Named peer} cut first-reply to <6h without doubling CX headcount.

Worth a quick chat?
```

Word count: ~55. Anti-pattern: don't quote the reviews verbatim.

## Template 3 — Hiring Support / CX

```
Hey {First},

Saw the {N} CX roles posted in the last two weeks. Real budget unlock.

The piece most teams undershoot at this pace is ramp tooling — {Named
peer} brought 8 new CX hires to first-solo-resolution in 2.5 weeks
instead of 6.

Want me to send the playbook?
```

Word count: ~50. Anti-pattern: don't make this sound like you're pitching tooling that replaces the new hires. The recipient is excited about the team growing.

## Template 4 — Socials Spike

```
Hey {First},

Saw the {X}% follower jump on {platform} this month. Marketing's doing
work.

The thing that usually breaks next is the operational side — {Named
peer who hit similar spike} prepped for it by {specific thing}.

Worth trading notes?
```

Word count: ~45. Anti-pattern: skip the congratulatory opener. Treat the spike as a setup line, not a compliment.

## Template 5 — Tech Stack (qualification + timing combined)

```
Hey {First},

Saw {Company} runs {Tech X}. Most of the {function} teams I work with
came from {Tech X} after they hit {specific scale point}.

{Named peer} switched at that point and saw {specific outcome with a
number}.

Curious if that maps to where you are?
```

Word count: ~50. Anti-pattern: don't pitch your tool as a Tech X replacement upfront. The first DM is about whether the friction is familiar, not whether you'll win the deal.

## Connection-request notes (300 char hard limit)

If sending an invitation note alongside the DM (or instead of, if not yet connected):

```
Hey {First} — saw the {one-sentence signal observation}. Worth
connecting if the topic's on your plate this quarter?
```

300 chars hard. Don't pitch in the invite — pitching in an invite is what makes recipients reject the connection request. Use the invite to land the connection, the DM to start the conversation.

## What changes by channel

| | Email | LinkedIn DM |
|---|---|---|
| Length | ≤ 90 words | ≤ 60 words |
| Register | Slightly more formal | Slightly more casual |
| First sentence | Reference the signal | Reference the signal (same) |
| Social proof | Named peer + outcome | Named peer + one-number outcome |
| CTA | "Worth a 15-min compare?" | "Worth a quick chat?" / "Want me to send X?" |
| Sign-off | "— First" | None (or first name only) |
| External links | OK in first email | NEVER in first DM |
| Emoji | Almost never | Match recipient's frequency |

## Don't reuse the email body as the DM

Same message, different channels = the recipient sees both and notices. They'll mark you as a templated bot and ignore everything. Distinct register, same angle, different sentence structure.

If the user explicitly wants a "matched pair", produce both from the signal angle but rewrite the DM to be shorter + more conversational. Never copy-paste from email to DM.

## Follow-up DMs

This skill drafts the FIRST DM. If a reply happens, follow-up handling is the user's outreach platform's job. If the user asks for a sequence:

- **DM 1** — signal-keyed (templates above)
- **DM 2** (D+5, if no reply): one-line callback + a piece of useful content. "Hey {First} — sending this regardless of whether the timing works: {one-line takeaway from a relevant resource}. No reply needed." ≤ 35 words. Builds reputation, not pressure.
- **DM 3** (D+14, "permission close"): "Hey {First} — going to stop bumping. Fine to drop a note when {X} changes?" ≤ 25 words.

LinkedIn DMs convert higher on touch 1 than email; subsequent touches degrade fast. Don't run more than 3 touches.
